# Planning supplemental release 1.3.4

This release completes the governed implementation-planning corpus through `CAP-19` and changes the automation decision policy without changing the authoritative Vision, Systems Design, backlog task structure, or approved product UI reference.

## Added planning coverage

- Four capability packets: `CAP-16` through `CAP-19`.
- Twenty-four individual slice implementation plans covering **72** authoritative tasks.
- Current official sources for semantic manuscript authoring, JATS 1.4 / MECA 2.0.1 interchange, DataCite 4.7 result/research-output metadata, RO-Crate 1.3 publication artifacts, peer-review terminology, independent review, editorial synthesis and revision.

## Completed recommendation policy

Every authored capability decision now has the researched recommendation stored as `selected_option`, status `accepted`, `decision_completion: complete`, and no open blocking decision. The capability remains `proposed` until one explicit human approval authorizes the packet and all slice plans. Reviewers can override a default before approval; non-recommended overrides require rationale. This removes repetitive decision stops while preserving accountable human authorization.

The planning corpus now contains **19 capability packets** and **111 slice plans**.
