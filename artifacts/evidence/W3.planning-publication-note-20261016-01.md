warnings. Publication then rejected the generated successors of

retention of those pages' already committed, admitted bytes. No privacy baseline,
admission, hook, generator, checker or product criterion changes. Another 614
checked publication files remain unchanged, including the current W2/G2/C36,
W3 and 13-Wave projections. The site manifest records source hashes and states;
it does not assert generated HTML digests for these retained pages.

positive because its key names `assets/tokens.css`. The value is independently
verified as that public CSS file's SHA-256, also matching active reference 1.9.
Only its ordinary YAML serialization changes from an inline scalar to a folded
scalar. The complete parsed mapping and digest value remain identical; the full,
unmasked scanner finds no credential in the revised manifest. Original bytes and
the finding remain preserved. No suppression or credential exception is added.

in that sidebar. Use `planning/review-site/index.html` and current Wave pages for
the updated roadmap. This is a disclosed historical-page presentation limitation,
not a product change or a new framework task. The ordinary full-byte checker PASS
belongs to the generated successor before retention; the final publication uses
that result plus the bounded exact-retention and unchanged-file proof. It is not
reported as a full-byte checker PASS for the retained final tree.
