# W1.A08.T02 current-navigation contrast remediation

Predecessor: `6db0918c453a9d9b66321c934764f70e0aa162fe`. Original claim base
`46e88d171795b76a2f1588d69756f4184c01a89b` is unchanged. Independent visual03
finding F01 extends the existing acceptance-closure map; it does not expand
authority. Approved reference 1.6 section 9 requires WCAG AA, and the reference
current-navigation pattern uses light text on a dark selection background.

The inherited product cascade instead uses brand-800/brand-50 (2.38865:1)
and inverse/brand-700 for the 12px current-step number (3.93622:1). Existing
palette checks and geometry samples missed these actual text consumers.

Before product edits, the new shared-style browser regression fails all three
dark viewport cases on the actual step-number computed colors. An initial
test attempt sampled before the reduced-motion 0.01ms transition completed:
its negative assertion failed to detect the injected color defect. Waiting
settled animation frames exposes the defect; that failed attempt is not
reported as a passing contrast check. After correcting only the marker pair,
the regression still fails all three dark cases on the label. Final sampling
requires two stable animation-free frames because inherited transitions can
settle over more than two frames. The paired corrections then pass the shared
CSS regression, which also rejects an injected restoration of the old label
color. Initial lint found three overlong JavaScript lines in that new test;
they were wrapped without changing behavior before final verification. The
first theme override exceeded the existing specificity bound; a zero-specificity
theme context restores the normal shared selector budget without an exception.
The initial built-product assertion expected both page and step in the unchanged
Task Center fixture, which has no Research Intent/progress reply: it failed on
missing step inventory, not contrast. That fixture now explicitly proves page
text only; the complete existing workflow observer supplies actual step proof.

An initial build command selected the host Node 20 launcher and failed before
build with a sandbox path error. Re-running with the repository's pinned Node 24
and pnpm succeeded. The initial isolated type command lacked the existing tools
module search path and found one nullable-regex typing issue; the proper tools
search path and explicit non-null assertion pass without suppressions.

Remediation uses existing approved palette tokens in shared current-navigation
rules, preserving labels, state/disabled predicates, callbacks, geometry and
token definitions. Proof covers direct rendered text nodes (page/step label,
number and metadata), both themes, three viewports, an injected adverse color,
and the actual built product using existing isolated adapters. Replay prior
flow, sidebar, keyboard and context-button findings; retain fresh source-bound
visual evidence and independent disposition. No credential, persistence,
domain-state or native-window change is involved. Full W1 qualification remains
a separate exit duty. No approval or finding closure is claimed here.
