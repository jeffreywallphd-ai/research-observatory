Review and verification cadence while the Wave runs

  1. Task: risk-selected checks plus a focused independent scope/evidence disposition; expand only for high-risk boundaries.
  2. Slice: independent risk-focused end-to-end and adversarial deep review.
  3. Integration checkpoint: accumulated affected-profile checks when a shared interface, migration, security boundary, or coherent risk cluster closes.
  4. Wave exit: the complete affected/full suite, packaging, security, accessibility, performance, restart, recovery, and independent Wave review.
