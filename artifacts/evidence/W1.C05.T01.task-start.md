The controller is cooperative, in-process admission for declared upper-bound
envelopes. It is not an OS sandbox, a multi-process quota enforcer, cumulative
spend accounting, or a scientific-compute scheduler. Explicit project concurrent
ceilings, demands and interactive reserve come from trusted runtime composition;
there is no unlimited fallback. No governed UI state or reference changes.

Independent task review will include affected regression/integration evidence.
Fresh full W1 qualification, worker measurements, current production packaging,
independent Wave review and human G1 remain separate. Retain Q's interrupted
full-matrix attempt04 and worker04's bounded class/queue evidence as historical,
