The integrated fixture creates a fresh protected project and synthetic private
source configuration through normal Core composition. DPAPI, SQLCipher, durable
workers, publication and cache are real. ASGI/native context and external HTTP
are explicit substitutions; no live provider is contacted. All four adapters
produce actual retained observations, followed by new confirmed cache invocations
with zero provider dispatch. Offline denial, provider failure/recovery and
in-flight cancellation preserve prior observations. A new Core runtime inspects
the exact projected last record/query and verifies the cancelled invocation
remains cancelled, unpublished and unable to advance its preceding checkpoint.
This is runtime restart, not an operating-system process-kill or installer test.

The public handoff consumer uses JSON schemas and serialized pages/retention,
without Core or storage imports. It preserves provider/assertion identities,
versions, query, response reference, OA host/license observations, graph seed and
direction, and restrictive action rights. Provider/time/partial substitutions
are rejected. A separate concurrent broker probe records actual clock/sleep
waiting and serialized requests; it explicitly substitutes authority, repository
and HTTP and is not protected-runtime concurrency proof.

The performance tool measures three fresh processes/projects with 100-record
OpenAlex/Crossref/Semantic Scholar pages and one-DOI Unpaywall responses, each
followed by a protected fresh-cache page. It includes preview/confirmation to
terminal job latency, actual hardware/OS, raw samples, min/median/max and process
peak working set. A separate actual-rate-wait sample accompanies every process.
No OS cache flush, minimum-hardware or live-provider latency claim is made.
Calibration is nonqualifying. Qualification compares every sample to the exact
independently reviewed baseline, with a 20% regression allowance and absolute
30-second/512-MiB ceilings. Those are benchmark gates, not new product deadlines.
Baseline creation and hash binding follow retained calibration and independent
review; the pending hash intentionally prevents a qualifying run now.

The runner requires a clean committed candidate and canonical producer/helpers,
locks selected source/contracts/fixtures and installed dependency files, records
their hashes, and checks identity again before atomic publication. It requires
`-B -s -X pycache_prefix=artifacts/tmp/<fresh-absent-prefix>` and gives each child
its own fresh cache prefix, preventing old bytecode from bypassing source hashes.
Reports are confined to ignored artifacts and are marked nonqualifying before
preflight; failures preserve adverse samples and cannot leave a stale PASS.
Raw child reports are parsed and hashed from the same byte snapshot.
