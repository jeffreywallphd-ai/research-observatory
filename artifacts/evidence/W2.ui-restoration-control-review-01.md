## Preserved preflight findings and closures

1. **Incomplete producer binding — closed.** The first draft could retain a
   classification after Core/client changes because it checked UI inputs only.
   The final linked route compares the complete existing capture producer with
   current authenticated inputs and rejects every later captured-input or
   admitted correction-path touch, including add/revert history. The real-Git
   classification case tests later Core edits/reverts and stale snapshots.
   Capture-reader tests separately exercise real PNG/inventory/delivery and
   producer-byte boundaries; the classification fixture's substituted pixel
   boundaries are not presented as product rendering proof.
2. **Approval after original execution — closed.** The approved packet must
   contain a NOT_STARTED origin, and its distinct approval introduction must
   precede the original claim base. The real-Git chronology fixture denies
   already active/completed packet origins and a claim preceding approval.
3. **Combined submit/review claim substitution — closed.** Ordinary taskctl
   delivery may legitimately combine submission and review. The final route
   binds the prior claimed owner/base, branch/worktree/platform/profile,
   review/experience fields and immutable task contract, plus prior/resulting
   attempt histories, exact packet, immutable evidence and independent ledger.
   Actual-history substitutions of branch, objective, worktree and platform
   now fail. The historical amendment default still rejects combined delivery.
4. **Residual packet chronology — closed.** The ordinary route additionally
   binds the first submission to the original base/branch and each remediation
   to the preceding candidate. Canonical Git ancestry must establish strict
   base to candidate to evidence delivery, followed by review delivery (the two
   deliveries may coincide). The real-Git regression covers unrelated roots,
   early/equal candidates, changed base/branch, reversed delivery and remediation.
