credentials, with no project open and Core ready. Alt+Space opened the Windows
system menu and reproduced status unavailability. The corrected renderer showed
the cleared locked-only view, truthful last-confirmed **No login**, no Windows
unlock/reset action, and an explicit full-application restart instruction.

capture lacked an accessibility tree; Control+End did not visibly scroll.
Alt+F4 closed the application, with exit zero and the entire owned tree drained.

53,475.4086 and 121,654.2461 ms. The last pre-gap router/body spans 107/108 returned
in less than one millisecond, well below the 512-span diagnostic cap. Return is
not proof of renderer delivery. No usable post-failure renderer diagnostic rows
were captured; native/renderer clocks and request identities are not correlated.
These observations support investigating callback delivery, not a proved
mutex deadlock or a proved scheduling remedy.

Pinned Tauri macro dispatch offers a bounded B: `#[tauri::command(async)]` keeps
the existing function, State argument, snapshot return and mutex-protected body,
while scheduling dispatch away from the synchronous WebView callback. Compare
actual native menu behavior before accepting it. Preserve the 1500 ms timeout,
failure latch, policy bytes, provider authority and explicit recovery rules.
