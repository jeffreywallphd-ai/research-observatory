What No login changes
It removes only the additional app prompt. Windows account isolation, encrypted project storage, local permissions, privacy and egress rules, and Core process protection stay active.

If Hello later becomes unavailable, retry it or choose explicit Windows-password recovery. Reset to No login appears only after the native password prompt proves this same Windows user; without that proof the app stays locked and points to Windows recovery.

Before this change is applied

Protection changes are previewed and atomically persisted.
  1. The destination provider is checked and, when enabling protection, verified.
  2. Reducing protection to No login requires verification by the current provider or an explicit same-user Windows-password recovery prompt before the warning and confirmation.
  3. The signed-in session, confirmation, or audit record alone cannot remove protection.
  4. The setting is written only after all required checks succeed.
  5. Cancellation, denial, failure, or a busy provider leaves the existing mode unchanged.
