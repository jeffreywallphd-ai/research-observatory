`W2-CORPUS-REPORT-PROFILE-R01-F01`: optional activation solely on
`tests/corpus_reports/test_*.py` would silently omit the command from W2 when
that directory was missing but `tests/reports` remained. This contradicted the
claimed fail-closed behavior. The R01 finding remains in this record. R02
makes the command required and tests both inverse missing-directory cases:
W2 still selects the command exactly once and the launcher exits 2. This
closes the identified selection risk subject to independent R02 review.
