# Local search contracts

Generated by `tools/core_api_contract.py` from Core's UI-independent
`research_observatory_core.search` declarations:

- `query-document.schema.json`: original/normalized query, typed AST and versions.
- `query-diagnostic.schema.json`: content-free codepoint locations.
- `analyzer-profile.schema.json`: selected analyzer identity/configuration.

These Draft 2020-12 schemas validate structural shape. Untrusted query snapshots
also require Core `load_query_document` for duplicate-key rejection, bounded
decoding, strict scalar types, Unicode policy and original/normalized/AST binding.
They carry private query content and must follow protected run storage policy.
See [the grammar and runtime boundary](../../../docs/architecture/search-queries.md).

Regenerate with `python tools/core_api_contract.py --write`; verify with `--check`.
This additive package does not replace the Core OpenAPI/generated client or the
external connector query DTO. A standalone headless launcher/AI mode is outside
this task.
