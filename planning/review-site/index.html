Planning review center

Review and approve one complete Wave packet, then execute its capability contributions and ordered slices as one durable campaign. Descriptive aliases are the default presentation; canonical numeric IDs remain immutable evidence keys.

How to use this site

  1. Select the Wave being activated.
  2. Review every contributing capability decision and ordered slice plan from the Wave page.
  3. Use the linked capability pages when you need full rationale or an override.
  4. Approve the complete Wave packet at one immutable commit; later Waves remain unapproved.
