# ADR-0059: Bounded portable local query snapshots

## Context

Approved CAP-06.S01.T01 requires a typed local query grammar, original and
normalized text, bounded parsing, location errors and portable contracts.
Accepted ADR-0057 and CAP-06-D01/D06 already select an engine-neutral AST and
unicode61/remove_diacritics2. Core must remain usable independently of the UI.
Existing connector SearchQuery is an external-source DTO with narrower semantics;
overloading it would silently change a previously delivered interface.

This Proposed record documents implementation details under existing authority.
It does not amend an Accepted decision, the locked Wave scope or experience
reference, and it supplies no new implementation or release approval.

## Candidates

1. Reuse connector/provider or raw FTS query strings. Smaller initial surface, but
   couples scientific intent to a provider/engine and loses explicit unsupported
   syntax, typed validation and reproducible normalization.
2. Add a separate immutable Core AST/query document, strict bounded loader and
   portable structural schemas through the existing generator. More validation
   code is required, but scientific intent remains UI/engine independent and
   existing connector/OpenAPI contracts remain available.

## Decision

Implement candidate2 in the pure Core search package. Frozen slotted standard
library dataclasses validate discriminated node shape and immutable child tuples.
The parser retains exact original codepoints, emits a deterministic normalized
query and binds schema/grammar/analyzer identities. Imports and serialization
reparse the original and normalized queries and verify the AST. Iterative tree
validation counts expanded occurrences and rejects forged cycles before recursive
comparison/serialization. Strict wire decoding limits bytes and container nesting
before JSON decode and rejects duplicates and coercive scalar types.

The grammar supports literal/phrase, named fields, integer year comparisons,
NOT/AND/OR and parentheses, with explicit unsupported forms. Literal syntax does
not promise byte/case/diacritic-exact retrieval. Source text/anchors remain
unchanged. The analyzer declaration is versioned separately from the grammar.
The detailed syntax, budgets, diagnostics and later compiler obligations are in
[local search queries](../architecture/search-queries.md).

Extend the existing contract generator additively with three search schemas and
register all new Python sources/tests in the existing quality scope. Do not
change prior generated artifact bytes, methods, paths or operation identities in
this task. No new controller, dependency, UI route or headless launcher is added.

## Consequences

Clients can parse and exchange typed queries without importing the desktop or a
web server. Content-free diagnostics avoid default query disclosure; intentional
snapshot serialization still carries private content and requires protected
storage in the owning run task. JSON Schema covers structure; Core import is
mandatory for semantic binding, strict Unicode/scalar policy and runtime budgets.

No persistent state, migration, operational audit mutation, key, rights grant,
index or HTTP route changes here. T02/T03 retain actual protected FTS/compiler,
authorization, generation/recovery and API/UI proof. All deployed profiles share
this pure contract; Windows x64 qualification follows the current Wave policy.
Removing this additive package before any dependent delivery is the bounded
rollback; already persisted future snapshots must retain their version identities
and cannot be relabeled by such a rollback.

## Verification

`tests/search/test_query_grammar.py` challenges precedence, all fields, Unicode,
normalization, location errors, strict snapshots, limits and diagnostic privacy.
`tests/search/test_query_contracts.py` validates generated structural schemas,
forged graphs, actual Core/JSON roundtrip in an isolated interpreter, and the
36-artifact/102-operation API predecessor fixture captured from the actual
claimed base. `tools/core_api_contract.py --check` verifies deterministic output;
fresh exact-candidate comparison authenticates all prior generated bytes.

Affected quality, architecture and ADR checks accompany commit-bound evidence
and independent task disposition. Protected disk/FTS, API search behavior,
UI/native conformance and full Wave qualification are not established by these
pure contract checks.
