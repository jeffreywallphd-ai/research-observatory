## Neutral participant tasks

1. Open the supplied application. Explain what it appears to be for, whether it
   seems ready, and what you would do first. Do not act on credentials prompts.
2. Set up a project called **Neighborhood Library Study** to find out how local
   libraries support adult learning. Choose the kind of research that seems
   appropriate and save it in the supplied Test-Documents folder. Say how you
   would know it was saved successfully.
3. Find where you would describe the study's purpose and boundaries. Save a
   draft explanation; find how to review it before treating it as final.
4. Find what to do next in the study. Visit a different available area, then
   return to where you left off without losing your study context.
5. Find out whether any work is currently running, waiting for you or finished.
6. Close the project without deleting it, then reopen it and check whether your
   work is still there.
7. Make the display comfortable for reading; find keyboard help and return to
   your study. Use the keyboard for one navigation action.
8. Find whether information would leave this computer, without changing any
   privacy/security setting or sending anything.
9. If you needed help, find information useful to support. Preview what would
   be shared and explain what you believe it includes/excludes. Do not send it.

Tasks 3–6 may use an independently prepared synthetic sample project if creation
blocks access; record that assistance explicitly and never count it as successful
